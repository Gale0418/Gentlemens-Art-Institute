# 1.0.5（80）驗證紀錄

日期：2026-11-11。此版接續已安裝於 Mac／iPad 的 1.0.4（79）。本紀錄整理上傳前的程式、實機及商店發行包驗證；商店處理結果另存於任務中心。

## 修正

- 授權檔案描述符的封存檔開啟路徑也檢查 8 GiB 輸入上限。
- iOS 外部檔案可用性檢查改由 blocking pool 執行，保留原有權限、錯誤與開書世代防護。
- 中繼資料由同一個已開啟檔案實際限制讀取最多 2 MiB 加 1 byte，超限即拒絕。
- 無書籍 ID 的關閉命令在生命週期鎖內原子退休舊 SMB 暫存目錄，再於背景清理退休目錄，避免誤刪新開書的下載。
- SMB 開書無法解析 App 專用資料目錄時會結束下載指示並回錯；兩種關閉路徑均不清理共用的全域暫存區。個別關閉的快取清理維持 best-effort，失敗時記錄診斷。
- 封存檔宣告的總解壓大小改採 8 GiB 硬上限，保留單 entry 128 MiB、entry 數量、名稱總量及整數溢位防護。合成 header 測試涵蓋正常 3 GiB 與超限案例，不配置 GiB 等級測試資料。
- `rusqlite` 固定為 0.41.1，`libsqlite3-sys` 為 0.39.1，內建 SQLite 3.54.1；修補 [RUSTSEC-2026-0459](https://rustsec.org/advisories/RUSTSEC-2026-0459.html)。另驗證實際連結引擎至少為修補版 3.54.0。
- Mac 商店設定移除舊 1.0.3 版本覆寫，繼承主設定的版本與 build number。
- AI 服務回傳 HTML 或空白錯誤回應時保留 HTTP 狀態，使原有 HTTP 錯誤處理與 Gemma 備援流程繼續生效；成功回應格式錯誤、串流讀取錯誤與 1 MiB 上限維持原規則。
- 支援頁移除過期的「未上架」敘述，加入正式商店連結。新錯誤文案、三語商店更新說明與支援頁修訂均經 Gemini 校稿。
- 新增可重現的第三方授權產生器與原文來源清單，涵蓋三個 Apple target 的 348 個第三方 Rust 套件及兩項 iOS 原生元件；原生 bundle 設定收錄 `THIRD_PARTY_LICENSES.txt`。材料覆蓋與法律認證分開，未杜撰上游未提供的著作權人。

## CodeRabbit 範圍與處置

先盤點 Git 已追蹤的第一方文字檔，再納入本機 patch 與遞迴 path dependency。`libarchive2-sys` 對照官方 crate 與 libarchive v3.8.9 原始碼後，納入本機 build／binding 設定及修改的 RAR5 C 原始碼；未修改的上游來源、二進位、私人資料與大型產生檔分開列明。小型產生設定、語系與圖像 manifest 也納入剩餘批次。

首個嘗試因 150 個原始檔加一份附加說明，被服務以 151 檔拒絕，沒有審查結果。後續每批為附加說明保留一個檔案名額，並保守計入每 rolling hour 最多三次嘗試。

前六個完成的批次分別回報 149、123、106、8、9、4 個檔案，沒有漏列。其中 123 檔是 120 個未審檔加上 3 個修正檔。已處理封存檔與 SMB 邊界、過期說明、AI HTTP 狀態、出貨授權清單，以及後續發現的產生器和 iOS staging 錯誤處理問題。最終批次把最新工具修正與本輪文件一起複審。覆蓋率依服務實際回報的 `reviewedFiles` 與檔案雜湊核對；大型產生的授權全文另以來源與封裝雜湊驗證，未修改的上游程式與二進位也不計入程式碼審查覆蓋。
