## 尚未完成的外部條件／擴充矩陣

- **真實 AI 推論**：已在 build 29 對 2 頁 `SmokeTestComic` 完成實際 API 回應與候選呈現；尚未在實機驗收長篇六頁取樣、候選語言隨介面切換、目前頁解說與供應商拒絕原因。使用者另回報自己的 AI 操作正常，與上述實機結果分開記錄。
- **AI 與全域掃描並行**：同一短篇在全域掃描中第一次操作顯示 `database is locked`；掃描結束後重試成功。此為 build 29 已重現的 SQLite 寫入競態，不列為通過，修補須另行驗收。
- **StoreKit / TestFlight**：目前是 development build；購買、恢復、重裝、退款撤銷與正式權益同步仍需相同 TestFlight build 的沙盒環境。
- **系統權限破壞性矩陣**：未撤銷現有照片／Files 權限，未移除使用者已連結來源；有限照片權限、離線 NAS、失效書籤與 iCloud 按需下載仍需隔離測試資料。
- **其他裝置／角度**：本輪沒有 iPhone、雙頁換向後繼續翻頁或全書隨讀 AI 翻譯的實機結果。COMIC-L22、COMIC-W25、COMIC-R27 與 COMIC-PQ22 仍不應標 Done。
