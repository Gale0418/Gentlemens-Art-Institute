# 書架側欄與回上層

> 歷史開發紀錄：下列測試數字與裝置狀態是當時的觀察，不代表最新版本已通過相同驗收。最新掃描維修紀錄見 [scan-progress-repair-2026-09-09.md](release/scan-progress-repair-2026-09-09.md)；未完成事項仍以任務中心追蹤。

## 需求與設計

保留既有主題與三欄書架，不改閱讀器翻頁操作。依 impeccable 的 adaptive 配置原則，側欄不能因直立或窄視窗而失去入口。

- 900px 以下：左右側欄採非模態抽屜，一次展開一側；預設收合，中央書架不因抽屜展開而縮窄。
- 900px 以上：維持並排，兩側可獨立收合；窄畫面的臨時操作不覆寫寬畫面的收合偏好。
- 左右 chevron 按鈕保留可辨識的無障礙名稱及至少 44px 觸控區。
- 中央書架提供「回上層」，回到來源內的上一層目錄；根目錄停用。
- 一般漫畫維持首次選取顯示詳情、再次選同一本開啟；內建示範漫畫既有直接開啟行為不變。
- 尺寸切換只同步側欄呈現與無障礙狀態，不重新讀取書庫或重建書架。

## 驗證狀態

- `npm test` 四組前端測試通過；包含窄畫面互斥、寬畫面獨立、尺寸切換不得 fetch/render、原生 inert 與 hidden fallback、收合焦點移交、逐層回上層、首次詳情／再次開書。
- `node --check public/app.js` 與 `git diff --check` 通過。
- Chrome 合成書庫 820×1180：實際點擊左右抽屜，確認可見、切換互斥，首次選書展開右詳情。
- Chrome 1180×820：左欄 220px、右欄 280px 並排，右欄可收合且入口仍可見。
- Chrome 390×844：兩側入口與根目錄停用的回上層可用；詳情寬 346px，文件無水平溢出。
- 實測發現並修正舊 `display:none` 壓過新抽屜，以及既有半透明材質造成書架透底；抽屜使用不透明主題表面。

瀏覽器合成資料測試只用於版面與互動檢查，不等同 iPad WKWebView、觸控或實機效能驗收。本次未重建或安裝原生版本；iPad／iPhone 模擬器截圖、實機旋轉與觸控仍待後續部署驗收。
