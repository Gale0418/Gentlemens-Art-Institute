## 商店介紹

漫畫存到硬碟深處，找一本還得像在考古？G.A.I 幫你把自己收藏的漫畫和圖集排成好找、好讀的書架。檔案由你提供；App 不附作品，也不提供下載。

ZIP、CBZ、RAR、CBR、7z、CB7 和圖片資料夾都能讀，不必先手動解壓。想一路往下滑就開條漫；習慣翻頁可以切單頁或雙頁，照你的閱讀習慣來。

點開資料夾先看這一層，整個書庫的掃描在背景繼續跑。搜尋、收藏、閱讀進度與基本標籤，幫你接回「上次看到哪本」。NAS 暫時離線，已整理的書庫紀錄也會留下來。

基本閱讀免費：本機檔案、三種閱讀模式、進度、收藏、搜尋、基本標籤、資料匯出與基本復原都能用。透過系統檔案選擇器開啟已掛載的 NAS 資料夾，也不用升級。

書庫大到標籤貼不完？v1 Pro 目前售價 NT$150，一次買斷，沒有訂閱。解鎖直接 SMB／NAS 連線、批次標籤、進階整理、重複作品候選，還有 AI 解說與整理工具。

AI 是選用功能，需要自備 OpenAI 或 Google API Key。選好服務商與要傳送的內容並同意後，App 才會送出你選取的頁面和提示文字。Pro 不含 API 額度，服務商費用另計；AI 給的是建議，確認後才會套用，不會直接蓋掉手動整理的內容。

G.A.I 不提供漫畫下載、來源爬取或內容訂閱。用自己有權使用的檔案，書架就由你作主。
