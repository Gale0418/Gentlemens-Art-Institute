# AI 多語驗證（2026-09-09）

## 已驗證

使用使用者指定、工作區外的 OpenAI 金鑰，實際呼叫生產設定的 `gpt-5.6-luna` Responses API。金鑰不保存在程式或報告中。

- 內建群山風景圖：繁中、英文、日文均回應相應語言，指出沒有可翻譯對白，未捏造漫畫角色或對話。
- 自製日文對話頁 → 繁中／英文；自製英文對話頁 → 日文：最終提示詞三組均完成，原文辨識、下午三點發車、請求兩張票、詢問遺漏物品的句意正確。
- 最終提示要求先列原文再翻譯，摘要限明確可見內容。前一輪曾出現「剪兩張票」與把請求描述成完成購買，因此保留失敗證據，不以 HTTP 成功代替語意驗收。

## 證據

本機資料夾 `output/release/2026-09-09-ai-localization/` 包含：

- `connectivity.json`：連線確認。
- `landscape-*.json`：風景三語結果（第一輪提示）。
- `dialogue-*-v3.json`：最終提示的三語對話結果。
- `production-prompts.json`：從 Rust 生產函式提取的最終提示。
- `quality-review.json`：人工語意檢查與限制。

## 尚未完成

這是使用生產提示與同一 API 請求格式的直接網路測試，尚不等於封裝 App 的 Pro 權益、設定、頁面擷取、快取與實機端到端流程通過。Google provider 未測；沒有提供 Google 金鑰。小樣本通過也不保證任意漫畫、手寫字或密集頁面都能正確翻譯。

完整 npm test 通過（含三語 payload、快取及晚回應隔離，577 翻譯鍵）。從目前 Rust 原始碼提取的 prompt 函式與對應單元測試，經 rustc 編譯執行通過；尚未執行整個 crate 的編譯／serde 測試。cargo fmt --check 仍有既有檔案格式差異，未趁此更動無關程式。英文／日文曾將艦載 AI 誤寫成本機 AI，已改成 Cloud AI／クラウドAI。
