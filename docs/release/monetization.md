# G.A.I 現行商業模式政策

本文件是目前收費政策的唯一依據，不是付款功能或商店狀態的即時證明。現行政策為免費核心功能與一次買斷 AI Pro；發行／交易證據另依相應紀錄核對。既有核准價格紀錄維持原狀，本次不調整定價。

## 文案的寫作前提

對外文案應按本政策描述產品，不混入施工狀態或 TODO。商品識別、實際價格及交易驗收狀態屬發行紀錄，不由此政策文件推定。

## 現行收費範圍

閱讀、裝置與系統已掛載來源、直接 SMB／NAS 連線、標籤（含批次）、手動整理、重複作品候選檢查、資料匯出，以及產品實際提供的撤銷與復原功能皆免費。只有使用者選用的雲端 AI 翻譯、解說與整理建議需要一次買斷 AI Pro。不得將撤銷／復原描述成涵蓋所有手動操作。

AI Pro 為一次買斷，沒有月費。已購權益不因未來推出其他方案而收回；新增功能則可能另售，不承諾所有未來功能免費。

AI 透過使用者選擇的雲端供應商處理。使用者自備 API Key、同意傳送後主動使用，API 費用另付給供應商；Pro 不送額度，也不保證第三方免費層。AI Pro 為同一個 App Store Apple 帳號在 Mac、iPhone 與 iPad 共用的一次買斷權益；Mac 使用 AI Pro 需要 macOS 12 或更新版本。

權益變更不應額外鎖住當下仍可用的 AI 結果；保存與匯出依各項功能實際提供的能力而定，不在此保證所有結果均持久保存或可匯出。正式支援資訊見[根目錄 SUPPORT.md](../../SUPPORT.md)；商店文案草案見 [store-copy-zh-TW.md](store-copy-zh-TW.md)。

## 批准矩陣

| 功能或資料安全能力 | 免費基本版 | AI Pro 買斷 | 發行備註 |
| --- | --- | --- | --- |
| 本機圖片、ZIP／CBZ | 包含 | 包含 | 核心閱讀路徑 |
| 正常閱讀模式 | 包含 | 包含 | 只宣傳最終包實際驗證的模式 |
| 閱讀進度、收藏、搜尋 | 包含 | 包含 | 核心目錄能力 |
| 基本標籤 | 包含 | 包含 | 單筆或基本編輯 |
| 資料匯出 | 包含 | 包含 | 不得以付費封鎖資料可攜性 |
| 產品實際提供的撤銷與復原 | 包含 | 包含 | 僅限有明確撤銷／復原功能的操作，不代表所有手動操作均可撤銷 |
| 權益變更前已可用的 AI 結果 | 可繼續使用 | 包含 | 不因權益變更額外鎖定；保存／匯出依個別功能而定 |
| 裝置、本機與系統已掛載來源 | 包含 | 包含 | 包含已掛載 NAS；不因來源是 NAS 而鎖定 |
| 直接 SMB／NAS 連線 | 包含 | 包含 | 使用者明確設定的連線 |
| 標籤（含批次）與手動整理 | 包含 | 包含 | 整理本身免費；不承諾所有操作均可撤銷 |
| 重複作品候選檢查 | 包含 | 包含 | 檢查候選不等於自動刪除或合併 |
| 選用的雲端 AI 翻譯、解說與整理建議 | — | 包含 | 一次買斷；使用者自備 API Key，供應商費用另計 |

免費版的資料匯出與產品實際提供的撤銷／復原功能，在沒有 AI Pro 權益時仍可使用。撤銷／復原只適用於明確支援的操作。

## 分發與交易證據

分發狀態與內購商品文案的審查狀態請查 [App Store Connect 回讀紀錄](gai-app-store-connect-metadata.json)。交易驗收結果以個別版本的實測紀錄為準。

後續版本仍須依實際 release build 留存購買、恢復、離線權益與退款／撤銷行為證據；TestFlight 沙盒權益不得流入正式環境。Review Notes 應描述該次提交版本實際可用的功能及已驗證行為。
