# 第73版驗證紀錄

版本：`1.0.4 (73)`　日期：2026-11-09

本輪改善首次閱讀體驗，並修正 iPad 更新後的閱讀紀錄來源識別及背景掃描空窗。沿用既有視覺、閱讀器、風景選集與資料儲存方式；沒有新增相依套件。

## 使用者可見的改變

- 首頁直述本機、外接硬碟與已掛載 NAS 的用途；可直接試讀原創風景，或加入自己的漫畫資料夾。
- 空書庫收起尚未使用的側欄及工具，保留閱讀紀錄與已啟用篩選的解除出口；加入漫畫後恢復原有版面與偏好。
- 來源選擇只允許一個進行中的請求，首頁與設定同步回饋；取消或失敗後可以重試。
- iPad 更新造成自身 Documents 容器路徑改變時，讀取紀錄會先對應同一邏輯書籍，再計數與分頁。全庫索引尚未完成時，可使用當次掃描已確認且實際可讀的檔案；找到對應項目時會合併更新開啟中的紀錄頁。
- 封面未載入時，書名與時間仍維持完整文字欄寬。
