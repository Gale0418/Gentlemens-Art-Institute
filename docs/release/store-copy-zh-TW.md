# G.A.I 商店文案

> 對論壇收藏者直接說痛點，功能與費用仍照實際產品寫。正式文字以 `store-localizations.json` 為準。

## 副標題

漫畫太多？滑成條漫就好

## 宣傳文字

把你本機、外接硬碟或 NAS 上的圖片與 ZIP／CBZ、RAR／CBR、7z／CB7 放進自己的漫畫書架。條漫、單頁、雙頁都能看；App 不附漫畫，也不提供下載。

## 商店介紹

漫畫堆成山，找一本像在考古？你的收藏值得一個真正好用的書架。

G.A.I 是閱讀你自己已存在本機、外接硬碟或 NAS 上的圖片與漫畫檔的工具。App 不附漫畫，也不提供下載。先選自己的資料夾，就能開始整理與閱讀。

G.A.I 直接讀取圖片資料夾與 ZIP／CBZ、RAR／CBR、7z／CB7，照順序排好頁面。想一路滑，就用條漫；想慢慢翻，就切單頁或雙頁。不必事先把原圖合併成巨圖。

點進資料夾，先看眼前這一層；整個書庫在背景繼續掃。搜尋、收藏、閱讀進度與基本標籤幫你找回「上次看到哪本」。NAS 暫時離線，已整理的書庫紀錄也會留著。

基本閱讀免費：本機檔案、三種閱讀模式、進度、收藏、搜尋、基本標籤、資料匯出與基本復原都能用。透過系統檔案選擇器開啟已掛載的 NAS 資料夾，也在免費範圍。

想整理得更痛快？v1 Pro 一次買斷，沒有訂閱。解鎖直接 SMB／NAS 連線、批次標籤、進階整理、重複作品候選與 AI 解說／整理工具。

AI 是選用功能，須自備 OpenAI 或 Google API Key，確認供應商與傳送內容並同意後才會送出選取頁面與提示文字。Pro 不附 API 額度，供應商費用另計；AI 建議由你審核，不會直接蓋掉人工整理。

G.A.I 不提供漫畫下載、來源爬取或內容訂閱。請使用自己有權使用的檔案。
