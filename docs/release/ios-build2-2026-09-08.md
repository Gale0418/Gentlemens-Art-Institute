## 本輪修正

- `stage-ios-build.sh` 在副本中備份並遷移舊 `app` Xcode identity 至 `gai`，保留既有 project.yml 的隱私、權限、圖示、方向與原生插件。
- 依 lockfile 在 APFS 上安裝 Node 依賴，避免 SMB 上 `.bin` 失去 symlink 語意。
- 使用 `bundle.iOS.bundleVersion = "2"`。初次 `--build-number 2` 匯出曾得到 `1.0.0.2`，已重新建置修正；不交付該舊版本。
