# G.A.I 支援頁（繁體中文草稿）

> **歷史草稿，尚未發布。** 目前支援內容與公開聯絡方式維護於[根目錄 SUPPORT.md](../../SUPPORT.md)；本檔不提供獨立公開 URL，也不取用其他產品的聯絡或政策內容。

G.A.I 是 iPhone／iPad 的本機與 NAS 漫畫閱讀器。回報問題請勿附 API Key、NAS 密碼、私人路徑或未授權圖片。

**匯入與照片權限**：「匯入圖片」會建立書庫副本；直接連結資料夾或相簿則讀取原來源。原始照片仍由 Photos 管理。要閱讀相簿，請點「連結相簿」；完整權限可列出相簿，有限權限只列出允許照片。清單為空時到「設定」>「隱私權與安全性」>「照片」> G.A.I 調整後重新整理。取消連結、撤權或清快取只處理 App 的連結、進度與快取，不刪 Photos 原圖；刪匯入副本前先備份／匯出。

**Pro／恢復**：v1 Pro 一次買斷、不含 API 額度。在同一 Apple 帳號點「恢復購買」。仍未解鎖時重啟 App、確認網路與帳號，再依 [SUPPORT.md](../../SUPPORT.md) 的公開管道回報版本／build 和錯誤文字。正式上架前仍須確認購買、恢復、離線及退款／撤銷流程。

**BYOK AI**：AI 是 Pro 選用功能；你須提供 OpenAI 或 Google API Key 並同意傳送目前頁面影像／提示文字。API 費用依供應商另計，G.A.I 不送額度。不要把 Key 寄給支援；先清除 AI 工作階段，再依供應商方式輪替或撤銷 Key。

**NAS／SMB**：確認裝置與 NAS 可互通，主機／IP、Share、帳號與密碼正確；遇逾時檢查 SMB、防火牆與 NAS 睡眠。直接 SMB 是 Pro 路徑；「檔案」中已掛載的 NAS 資料夾仍可免費閱讀。停止連線請按「清除連線」。

仍有問題請依 [SUPPORT.md](../../SUPPORT.md) 回報，並提供版本／build、裝置、iOS、重現步驟及不含私人內容的錯誤訊息。
