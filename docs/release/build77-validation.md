# 第77版：寫實藏書庫背景驗證

版本：`1.0.4 (77)`。日期：2026-11-10。基底：`f345e2c`。

目前狀態：Mac 最新候選已完成實機驗收；iPad 頂欄修正版已建置及驗簽，但裝置鎖定且傳輸曾中斷，尚未安裝及完成橫直畫面驗收。尚未推送 GitHub main。

## 變更範圍

- 改用大尺度雙層木書架、暖黃閱讀燈與長廊的寫實背景。單張底圖覆蓋整個視窗，頂欄、並排資料夾側欄、詳情與繼續閱讀以淡暗色襯底連成同一空間。
- 頂欄移除既有模糊，保留可辨認的木紋與屋頂樑；背景暗罩仍維持76–88%，不影響封面的主角層次。
- 全視窗共用靜態底圖；不新增模糊、動畫、計時器或背景網路下載，原極光背景停止繪製。漫畫封面維持原色與既有大小。
- 直立採偏左取景，保留木書架與長廊；窄螢幕抽屜維持實色避免透出下面的書名。閱讀器仍是不透明黑底。
- 本機 JPEG 為 2048×1280、654,238 bytes。資產 SHA-256：`67aea09bee92a35039bf410a77cce104f390d44b56eaf9878d1d00d13f0ccfd6`。四主題文字保守對比下界皆達 4.5:1；此界線只涵蓋直接繪於底圖上的主文字與次要文字，不代表完整無障礙稽核。
- 不修改 JavaScript、Rust 閱讀／掃描／存檔邏輯、資料庫結構或既有三語介面文案。

Mac 測試使用自製風景 CBZ，完成後還原自動語言、紅色主題、150px封面與 `/Volumes/NASDisk/H`。NAS 根目錄及原有續讀已顯示，使用者確認的第4頁仍保留；不宣稱已量測完整 NAS 掃描時間。

Mac 的 ad hoc 更新曾遇 Documents 授權 code requirement 不匹配，系統記錄進入 prompting，讀檔停在 `open(2)`；沒有明確 deny 或 Rust deadlock 證據。原生選擇器重選該資料夾後立即列出書目。同一程式、同一份 CBZ 放入不受 Documents 限制的 Caches 後，索引、封面、換書與冷啟動正常。沒有因此擴大磁碟權限或修改產品邏輯。

本機測試更新後如遇受保護資料夾等待，可由「設定 → 加入漫畫來源…」重選同一資料夾，沿原有授權流程重新確認來源。

## 驗證限制

未量測 FPS、記憶體、溫度或耗電；10 MiB RGBA 為圖片尺寸推算，並非實測記憶體。未重跑 VoiceOver、真實 NAS 斷線、最低系統版本裝置矩陣與 iPad 多工矩陣。前端測試中的原生/GPU stub 不作實機證據。沒有 Rust 邏輯變更，因此本輪未重跑完整 cargo test/clippy；兩平台原生建置會編譯 Rust。

原生、資料保存、外部審查與獨立專家複審收據存於私有驗收目錄及 Mission Center；私人書架、原始資料庫與 API 金鑰不進 Git。
