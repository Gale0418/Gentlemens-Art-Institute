主人於 2026-09-08 指定：商店草案以 Mission Center 首發功能與驗收全部完成、正式上架時的產品為前提。對外正文直接介紹可用功能，不混入施工狀態、TODO 或實作提醒；這是文案時點的設定，不是提前變更任務狀態。實際進度、價格、商品識別與交易證據仍由本文件、商店 metadata 及 Mission Center 追蹤。未提供裝置端 AI、API 費用另計及買斷範圍都是正式產品條件，正文保留。

## 我們打算怎麼收費

G.A.I 先讓人免費把漫畫放進來，好好讀完一本。基本閱讀、搜尋、收藏、進度和標籤都能用；收藏多了，需要直接連 NAS、整批整理或 AI 幫忙時，再一次買斷 v1 Pro。

買斷的是 v1 的 Pro 功能，沒有月費。已購功能會保留，未來推出 v2 或其他方案，也不會收回；大版本新增的功能則可能另售，不承諾所有未來功能免費。

AI 透過使用者選擇的雲端供應商處理。使用者自備 API Key、同意傳送後主動使用，API 費用另付給供應商；Pro 不送額度，也不保證第三方免費層。不在 iPad 下載或執行 AI 模型，不新增本機 OCR 推論流程。

免費使用者也能匯出資料、撤銷操作和復原。已經整理好的資料與 AI 結果會保留，不因失去 Pro 權益就被鎖住。正式對外介紹見 [商店文案草案](store-copy-zh-TW.md)。

## StoreKit 與驗收閘門

在正式包可送審前，必須補齊並留存以下證據：

1. 由 ASC 建立的實際 Pro Product ID、價格與地區設定。
2. StoreKit 購買成功、重啟後權益恢復、離線狀態下的既有權益判定，以及撤銷／退款後權益收回。
3. 實際 release build 的交易與權益紀錄；不能用文件或 mock 宣稱已支援 IAP。
4. TestFlight 完整功能測試與正式環境隔離證據。沙盒購買或測試權益不能讓正式包無購買就解鎖 Pro。
5. 審查流程能驗證免費核心閱讀，也能在正式包可用時驗證購買、恢復、離線與 revocation 行為。

在上述證據完成前，ASC metadata 維持 `draft-blocked`。Review Notes 可以揭露預定的 Pro 權益，但不得寫成目前已可購買或已完成 StoreKit 整合。
